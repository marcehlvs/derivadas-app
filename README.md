# Derivadas en acción
App React + Vite: derivadas por definición, regla de la cadena, recta tangente, estudio de función y desafío.
`npm install` · `npm run dev` · `npm run deploy` (gh-pages). Contraseña de las ayudas: `src/config.js`.
Campo de respuesta: ÷ arma una fracción (numerador arriba, denominador abajo), xⁿ / x² / eˣ abren un exponente y ▶ lo cierra. `npm test` prueba el editor (`src/mathEditor.js`).
